# Repair-clock Coq witnesses

Machine-checked, admit-free proofs that a 2-coordinate clock characterizes
happened-before on the literal nomadim PG posets used in the repair-clock
experiment: a minimal fully-synced block and a crown's one-sync repair each
have order dimension exactly 2, so two integer coordinates suffice to capture
their causal order — sub-vector-clock memory at these scales. The proofs
connect directly to the project's north star (CLAUDE.md): an execution poset of
dimension d < N requires only d, not N, clock coordinates. Everything proved in
Coq here is admit-free; `Print Assumptions` results are recorded below.

## The three witnesses

All witnesses are literal nomadim PG posets. Events are numbered from 0; the
carrier is `Fin.t n`; the order is the reflexive-transitive closure of the PG
edge list, given as an explicit boolean match-table in `WitnessData.v`.

| Name | Syncs | Events | Coq dim result |
|------|-------|--------|----------------|
| **W_block** | N=2, `[(0,1)]` | 5 | `block_dim_eq_2` (dim = 2, Qed) |
| **W_repair** | N=4, `[(0,1),(2,3),(0,3),(0,2),(1,3)]` | 19 | `repair_dim_eq_2` (dim = 2, Qed) |
| **W_crown** | N=4, `[(0,1),(2,3),(0,2),(1,3)]` | 16 | defined as `W_crown_order`; dim 3 by z3 (deferred in Coq) |

W_repair is W_crown with the repairing sync `(0,3)` inserted.
W_block is the minimal fully-synchronized 2-process execution (single sync).

## Theorems

| Theorem | File | Meaning |
|---------|------|---------|
| `realizer_keys_dim_le2` | `FinPosetBool.v` | Reusable bridge: two injective key functions `k1,k2 : Fin.t n -> nat` that are monotone along `Rb` in both directions give `dim ≤ 2` (explicit 2-realizer); requires an incomparable pair to make the two linear orders distinct. |
| `block_dim_le_2` | `BlockDim2.v` | W_block has dim ≤ 2 (via `realizer_keys_dim_le2`). |
| `block_dim_ge_2` | `BlockDim2.v` | W_block has dim ≥ 2 (incomparable events 3 and 4). |
| `block_dim_eq_2` | `BlockDim2.v` | W_block has dimension exactly 2. |
| `repair_dim_le_2` | `RepairDim2.v` | W_repair has dim ≤ 2 (via `realizer_keys_dim_le2`). |
| `repair_dim_ge_2` | `RepairDim2.v` | W_repair has dim ≥ 2 (incomparable events 8 and 9). |
| `repair_dim_eq_2` | `RepairDim2.v` | W_repair has dimension exactly 2. |
| `W_crown_order` | `RepairDim2.v` | W_crown order defined; dim 3 by z3 oracle (`CLOCK_RESULTS.md`); concrete Coq proof deferred (see scope note). |

## Assumptions audit

`Print Assumptions` on all four results (run 2026-06-05, exit 0, `_audit.v`):

All four theorems have the same axiom set:

```
RelationalChoice.relational_choice
PropExtensionality.propositional_extensionality
ProofIrrelevance.proof_irrelevance
FunctionalExtensionality.functional_extensionality_dep
ClassicalUniqueChoice.dependent_unique_choice
Description.constructive_definite_description
Classical_Prop.classic
Ensembles.Extensionality_Ensembles
```

All are standard Coq Stdlib axioms (Classical, Ensembles, ProofIrrelevance,
FunctionalExtensionality, RelationalChoice, Description). No `False`, no `admit`,
no non-standard assumptions. The classical/choice axioms are inherited from
`dushnik_miller_exists` (the existence half of the Dushnik-Miller theorem used
to obtain a dimension from a finite realizer).

## Scope note

The positive (dim ≤ 2) side is proven admit-free for W_block and W_repair.
The concrete crown (W_crown, 16 events) has dim 3 by z3 (`CLOCK_RESULTS.md`),
but the Coq proof of dim ≥ 3 for W_crown is deferred: concrete PG crowns contain
no induced abstract crown3 subposet, so the certificate for `dim ≥ 3` requires
an alternating-cycle critical-pair witness for this specific poset, which has
not yet been formalized. The abstract obstruction *type* is proven as
`FrontierCompose.crown3_dim_ge_3` (the S3-frontier poset has dim ≥ 3, Qed,
admit-free).
